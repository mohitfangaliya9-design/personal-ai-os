# NEXORA

Premium black-and-gold public storefront interface.

## Included

- Responsive luxury homepage
- NEXORA brand identity and navigation
- Honest empty-state catalog with no fabricated products, reviews, prices, discounts, or sales statistics
- Curated collection preview sections
- FAQ and Instagram contact link
- Mobile-first layout with accessible native disclosure components

## Current limitation

This branch currently contains the storefront interface only. Live product persistence, authentication, admin operations, private file storage, payment verification, protected downloads, reviews, and deployment require a backend/database/storage/payment environment and credentials. No live payment or download claim is made by this interface.
